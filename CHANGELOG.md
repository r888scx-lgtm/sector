# 0.3.6 — experimental

- Russian, English and Simplified Chinese interface, help and application messages.
- Immediate language switching and persistent per-user language preference.
- Chinese UI font and translated disk lists, status, progress, support and overwrite confirmation.
- Disk selections, serial matching and consent checks preserved when changing language.
- Public distribution contains compiled applications and documentation only.
- 173 cloning tests, 1,065 localization/UI assertions and 12 isolated PowerShell checks passed; no physical devices were written during release verification.

Hardware compatibility remains experimental. This release does not constitute validation on every SSD or boot configuration.
