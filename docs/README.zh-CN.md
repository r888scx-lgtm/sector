# Sector 0.3.6 — Windows x64

作者：**by.mask21**。实验性 SSD 克隆工具，应用源代码不公开。

## 启动与语言

1. 从 Releases 下载 `Sector-0.3.6-Windows-x64.zip` 并完整解压。请将两个 AlphaVSS DLL 保留在 EXE 的同一文件夹中。
2. 需要 Windows x64、Windows PowerShell、.NET Framework 和 Microsoft Visual C++ 2019/2022 x64 运行库。本程序面向 Windows 10/11 x64 开发，其他配置尚未验证。
3. 以管理员身份运行 `Sector.exe` 进行克隆。`Sector-Preview.exe` 使用演示磁盘，无法写入物理设备。
4. 在窗口顶部选择 **Русский**、**English** 或 **简体中文**。语言立即生效，并保存至 `%LOCALAPPDATA%\Sector\settings.json`。执行操作时无法切换语言。

## 迁移 Windows

1. 连接目标 SSD。其物理容量必须大于或等于源磁盘，逻辑扇区大小必须与源相同，且为 512 或 4096 字节。
2. 在 Windows“磁盘管理”中**仅将目标磁盘设为脱机（Offline）**。运行 Windows 的源磁盘应保持联机。若目标为只读，其卡片中的“解除写保护”按钮仅更改软件只读标志，不会开始克隆。
3. 左侧选择源磁盘，右侧选择目标磁盘，点击“检查方案”。也可先执行“测试 VSS（不写入）”以检查快照的创建和读取；此测试不验证克隆操作本身。
4. 点击“克隆 SSD”。预检查完成后，输入 Windows 显示的目标磁盘序列号，并勾选同意覆盖。USB 适配器报告的序列号可能与 SSD 标签不同，甚至可能全部为零。
5. 等待复制、完整校验及引导准备全部完成。停止操作或出错会留下不完整的副本。程序无法恢复目标磁盘的原有数据。
6. 成功完成后，请关机并断开源 SSD，然后首次测试从副本启动。复制或校验期间，请勿将目标磁盘设为联机。

## 支持范围

- 基本 GPT 磁盘上运行中的 Windows：Windows 和 EFI 必须位于同一源磁盘。通过统一的 VSS 快照集复制 NTFS 卷。副本反映快照时的状态，不含后续更改。EFI 及分区布局单独检查。
- 动态 GPT 源磁盘：仅支持当前 Windows 所在的一个 NTFS **简单卷**，且 EFI 必须在同一 SSD。目标上重新创建基本 GPT、16 MB MSR、EFI 引导文件和系统卷映射。不支持跨区卷、镜像卷、额外用户卷及未知 GPT 分区。
- 两个脱机的非系统磁盘：完整逐扇区复制并逐字节校验。分区大小保持不变；较大目标磁盘的剩余空间不会自动加入分区。
- 不支持运行中系统的 MBR、运行中系统复制模式下的 BitLocker、RAID、虚拟磁盘、容量较小的目标、不同逻辑扇区大小或自动调整分区大小。

所有复制数据都会重新读取。VSS 副本通过写入前保存的数据块 SHA-256 校验。所有语言下均保留磁盘标识符和状态检查。
